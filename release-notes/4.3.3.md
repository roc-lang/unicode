# Unicode 4.3.3

- Upgrade Roc to the compiler pinned in [`.roc-version`](https://github.com/roc-lang/unicode/blob/4.3.3/.roc-version).
- Upgrade all examples to basic-cli 0.28.1 and coverage-guided fuzz targets to
  roc-fuzz 0.6.2 for compatibility with the updated compiler.
- Fix Linux test executables to use musl's self-relocating static-PIE startup
  object, built from the selected Zig toolchain.
- Rename internal bindings that shadow module definitions so the package passes
  the updated compiler’s duplicate-name checks.
- Refresh exact allocation baselines after the compiler eliminated allocations
  for long string literals used by the test harness; retain the allocation
  scaling checks.
- Keep the script type in its defining data module, resolving compiler type
  checking issues without changing the public API.

Unicode data remains at 17.0.0. Public Unicode APIs and default behavior are
unchanged.
