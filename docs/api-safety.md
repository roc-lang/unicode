# Public API safety audit

Public operations accept a valid Roc `Str`, arbitrary bytes through the
explicit UTF-8 decoder, sealed values, or checked caller-supplied bounds.
See [design.md](../design.md) for the shared invariants and
[testing.md](testing.md) for evidence review.

Traversal costs exclude work and storage chosen by a callback. All complete
text walkers use iterative loops and constant traversal stack. The narrow
generated Unicode lookups have fixed direct/paged indexing or a checked
binary search over a fixed table. Alias parsing compares against a versioned
finite vocabulary. A byte or scalar range contains integers and keeps no
source reference. A host allocator failure can terminate the process.

Run `python3 scripts/check_api_safety.py` to compare the inventory with the
public package and review all explicit foreign-input panic and invariant
extraction sites. Update the affected row when changing a contract or adding
an operation. The check verifies coverage; review verifies the justification,
including checked and range-proven arithmetic in reachable helpers.

`E0 A0` prefix by testing the exact endpoints and the effect at every chunk
cut. The ordinary suite runs the unmodified decoder. Bidi P1 lookahead was
reviewed with a separately enumerated short history matrix.

extension key order. The UTS #35 normalization fixture fails when `nu`
appears before `ca` in the formatted Unicode extension.
